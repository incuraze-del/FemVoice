# FemVoice — VST3: мужской голос → женский

## Сборка (Windows)
1. Установи Visual Studio 2022 (Desktop development with C++) и CMake, Git.
2. В папке проекта:
   ```
   cmake -B build -G "Visual Studio 17 2022"
   cmake --build build --config Release
   ```
   (JUCE скачается сам.)
3. Готовый плагин: `build\FemVoice_artefacts\Release\VST3\FemVoice.vst3`
   Скопируй его в `C:\Program Files\Common Files\VST3\` и пересканируй плагины в DAW.
   Там же есть `Standalone\FemVoice.exe` для быстрой проверки.

macOS/Linux: `cmake -B build && cmake --build build --config Release`.

### Без установки Visual Studio
Залей папку в пустой репозиторий на GitHub → вкладка **Actions → Build VST3 → Run workflow**.
Через пару минут внизу страницы запуска появятся готовые `FemVoice.vst3` для Windows и macOS.

## Как пользоваться
- Ставь на один вокальный трек, **сухой голос** (без реверба/дилея/бэков до плагина).
- Пресет **Natural**, потом подстрой: Pitch +5…+9 st, Formant +10…+25 %.
- Шар в центре: тянуть вверх/вниз — Pitch и Formant вместе. Двойной клик — сброс.
- Breath — добавляет придыхание, Air — яркость верхов, Mix — сухой/обработанный.
- Задержка плагина 40 мс (DAW компенсирует при записи и миксе).

## Что добавлено в этой версии
- Защита от октавных ошибок детектора высоты (главная причина «скачков» голоса на живом вокале).
- Срез низов (70–200 Гц), растущий вместе со сдвигом высоты: убирает «грудной» резонанс, выдающий мужской голос.

## Ограничения (честно)
- Лучше всего работает на одном голосе без обработки. Шёпот, хрип и крик — слабое место любых PSOLA-алгоритмов.
- Сдвиг больше +9 st или форманты больше +25 % начинают звучать как «мультяшный» голос.
- Задержка 40 мс — для записи с мониторингом через DAW; для живого выступления это ощутимо.

## Как работает
YIN определяет высоту → питч-синхронные зёрна (PSOLA) → Pitch меняет период
расстановки зёрен, Formant независимо растягивает/сжимает спектральную огибающую.
